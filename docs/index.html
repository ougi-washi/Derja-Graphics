Graphics?

Graphics, yaƐni ay ħaja relié b'el visuals f'el electronics (pc, talifoun, robot b'écran, console, etc...).
Hedha el guide yrakkez Ɛal "Graphics Engineering" w howa demaine matloub barcha surtout f'el sécteurèt hedhom:
- Video Games
- Architecture Visualization
- Audio Visualizers
- Image Processing
- etc.

Graphics Engineering lezmou barcha waq̈t w dedication. Ken et'tabbaƐ mƐaya waħda waħda, tnajjem tasnaƐ el graphics eli t'ħeb Ɛlihom.
Fama barcha tools tnajjem testaƐmelhom b'el techniquèt eli tetƐallamhom f'hal guide.
F'el cas mteƐna, les examples yestaƐmlou ShaderToy w chwaya Unreal Engine. Enty tnajjem testaƐmel Unity, Blender, ThreeJS, WebGL, VRay, l'engine mteƐek.. dabbar rassek.

Chnou lezmek tkoun taƐref?

Hal guide fih programmation, donc lezem ykoun Ɛandek base f'el programmation, ħatta chwaya.
El language eli bech nestaƐmlouh esmou GLSL (Graphics Library Shader Language). Aq̈rab language l'el GLSL howa C.
Graphics engineering fiha barcha maths (linear algebra), ama matkhafech, nħawel nfassarhom waq̈t nchoufouhom.
